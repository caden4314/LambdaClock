# Archived Lambda Display Lab

The multi-demo Lambda Display Lab that was active on `main` has been archived as of September 8, 2026.

## Exact snapshot

- Commit: `e1238e72a259f04a95fd68fc441d75cabf695f65`
- Commit message: `Synchronize lambda displays at 10 Hz`

That commit is the canonical frozen snapshot of the combined lab before the project shifted focus to the pure-lambda 3D cube experiment.

## Preserved demos

The existing demo source and standalone directories remain in the repository unchanged, including the clock, wave, oscilloscope, Lissajous, chaos, Fourier, logic, numbers, Game of Life, reducer, pendulum, Julia, Rule 30, sorting, SKI, Fibonacci, Collatz, sieve, random walk, Lorenz, particles, image function, benchmark, and related experiments.

Nothing was deleted. The root page can now evolve independently while the old lab remains recoverable from Git history and its existing source files.
